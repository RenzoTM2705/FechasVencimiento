# SEO_LAUNCH_CHECKLIST.md

> Aplicar según tipo de sitio. Una landing de una sola página no necesita crear páginas legales ficticias ni datos estructurados innecesarios.

## Antes de publicar
- [ ] Definir objetivo de búsqueda y una intención principal por página.
- [ ] Redactar title y meta description únicos, precisos y no engañosos.
- [ ] Usar URLs legibles y canonical absoluto correcto.
- [ ] Revisar H1 único y jerarquía H2/H3 lógica.
- [ ] Añadir alt a imágenes informativas; alt vacío a decorativas.
- [ ] Crear favicon y Open Graph image; probar vista previa al compartir.
- [ ] Generar sitemap con URLs canónicas indexables.
- [ ] Configurar robots.txt sin bloquear recursos necesarios; permitir indexación en producción.
- [ ] Añadir redirecciones 301 y consolidar www/no-www y HTTP/HTTPS.
- [ ] Añadir datos estructurados solo para entidades/contenido real y validarlos.
- [ ] Comprimir imágenes y servir formatos modernos cuando sea compatible.
- [ ] Revisar Core Web Vitals y rendimiento en móvil.
- [ ] Verificar enlaces internos, externos y páginas 404.

## Después de publicar
- [ ] Verificar dominio y sitemap en Google Search Console.
- [ ] Verificar sitio en Bing Webmaster Tools si resulta útil.
- [ ] Configurar ficha de Google Business Profile solo para negocio elegible y con datos reales.
- [ ] Revisar indexación, errores y rendimiento periódicamente.
- [ ] Medir conversiones con analítica aprobada y consentimiento cuando corresponda.

## Legal y consentimiento
- [ ] Política de privacidad según datos realmente recopilados y jurisdicción aplicable.
- [ ] Aviso de cookies/consentimiento según cookies, tecnologías y leyes aplicables.
- [ ] Términos y condiciones solo si el servicio/negocio los necesita.
- [ ] Aviso legal/contacto con información real aprobada.
- [ ] No generar texto legal definitivo automáticamente; solicitar revisión del propietario o asesor legal.
